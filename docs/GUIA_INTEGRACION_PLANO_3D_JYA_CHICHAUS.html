Código de inserción para Elementor Pro en loomcartagena.com — J&A Marketing Digital (Chic Haus)
Destinatario J&A Marketing Digital (Chic Haus)

Parámetro Exclusivo inmobiliaria=chichaus-ja

Resumen de Funcionamiento

  • Atribución exclusiva Chic Haus (J&A): El visor identifica automáticamente su canal comercial mediante inmobiliaria=chichaus-ja.
  • Sin desvíos externos ni pestañas duplicadas: Cuando un visitante explora el plano incrustado dentro de loomcartagena.com y pulsa "Separar Lote" o el botón de contacto superior, toda la acción ocurre en la misma pestaña.
  • Apertura automática del Popup de Elementor (#355): Dado que el formulario de GoHighLevel en loomcartagena.com vive dentro del Popup #355 de Elementor Pro, el código de abajo incluye un listener ligero que abre automáticamente su formulario emergente en cuanto el usuario hace clic en "Separar Lote", conservando todos los parámetros UTM (utm_source, fbclid, gclid) sin recargar la página.

1. Código para Incrustar en Elementor (https://loomcartagena.com/)

  1. En el editor de Elementor de https://loomcartagena.com/, creen una sección o contenedor de ancho completo (Full Width) donde deseen ubicar el Masterplan Interactivo.
  2. Arrastren un widget HTML y peguen íntegramente cualquiera de las dos opciones siguientes:

Opción A (Recomendada): Selector de Etapas 2D + Showroom + Maqueta 3D

HTML Widget HTML Elementor — Masterplan Completo (2D + Showroom + 3D) 
<iframe
  src="https://www.masterplanalmabeach.com/loom?inmobiliaria=chichaus-ja&embed=true"
  title="Masterplan Interactivo 3D — LOOM Cartagena"
  width="100%"
  height="720"
  style="border:0; border-radius:16px; width:100%; min-height:680px;"
  allow="fullscreen"
  loading="lazy"
></iframe>
<script>
window.addEventListener("message", function (e) {
  if (!e.data || e.data.type !== "LOT_SEPARATE_CLICKED") return;
  if (e.source) e.source.postMessage({ type: "LOOM_PARENT_HANDLED" }, "*");
  if (
    window.elementorProFrontend &&
    window.elementorProFrontend.modules &&
    window.elementorProFrontend.modules.popup
  ) {
    window.elementorProFrontend.modules.popup.showPopup({ id: 355 });
  } else {
    var btn = document.querySelector('a[href*="popup%3Aopen"]');
    if (btn) btn.click();
  }
});
</script>

2. Soporte Opcional para Sección Fija con ID en Elementor

Si más adelante deciden colocar el formulario de GoHighLevel en una sección fija dentro de la página en lugar de un Popup (por ejemplo, asignando en Elementor Avanzado → CSS ID: formulario), basta agregar &ancla=formulario al src del <iframe>:

https://www.masterplanalmabeach.com/loom?inmobiliaria=chichaus-ja&ancla=formulario&embed=true

4. Datos del Lote Seleccionado vía postMessage (Opcional para GTM / CRM)

Cada vez que un usuario pulsa "Separar Lote", el visor envía en e.data.payload la información del lote por si desean registrarla en Google Tag Manager o en un campo oculto de GoHighLevel:

JSON Estructura del evento postMessage recibido en loomcartagena.com 
{
  "type": "LOT_SEPARATE_CLICKED",
  "payload": {
    "lotId": "B-22",
    "price": "$267,957,400",
    "area": "252.79",
    "advisor": "chichaus-ja"
  }
}
